# Banking Operations & Transaction Analytics

## Project Overview

This project focuses on analyzing banking operations and transaction data to generate meaningful business insights using SQL, Python, and Power BI. It covers customer behavior, transaction trends, loan performance, repayment patterns, and branch-level operations to support data-driven decision-making.

## Objectives

- Analyze banking transactions to identify trends and patterns.
- Examine customer demographics and account activities.
- Evaluate loan distribution and repayment performance.
- Analyze branch-level banking operations.
- Develop interactive Power BI dashboards for business reporting.
- Use SQL and Python for data extraction, analysis, and data visualization.

## Tools & Technologies

- **Programming:** Python
- **Database:** SQL
- **Data Analysis:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Business Intelligence:** Microsoft Power BI
- **Environment:** Jupyter Notebook

## Dataset Description

The project uses the ABC Commercial Bank dataset, consisting of six CSV files:

| File Name | Description |
|---|---|
| accounts.csv | Account information |
| branches.csv | Branch information |
| customers.csv | Customer information |
| loans.csv | Loan information |
| repayments.csv | Loan repayment records |
| transactions.csv | Banking transaction records |
